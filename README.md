# Проект: Распознавание 35 пород кошек и собак

Данный проект выполняет классификацию изображений кошек и собак по 35 породам с использованием `PyTorch Lightning`. Для управления экспериментами используется `MLflow`, а для контроля данных — `DVC`.

---
## Особенности проекта
- Оптимизатор: Adam
- Лосс-функция: Кросс-энтропия
- Метрика качества: accuracy
- Размер изображеий: 224x224
- Версионирование экспериментов: mlflow
- Версионирование данных: dvc (сделано локлаьно в учебных целях без s3)
- Гиперпараметры обучения: hydra
- Логирование: hydra, pl


---
## Основные возможности
- **Обучение модели**: Запуск процесса обучения с настраиваемыми параметрами
- **Тестирование модели**: Оценка точности обученной модели на тестовых данных
- **Инференс**: Классификация нового изображения

## Команды для запуска (setup)
Сборка проекта:
```bash
uv sync
docker compose up -d
```

Загрузка данных:
```bash
./get_data.sh
```

- Указываем в `config.yaml`:
  - гиперпараметры обучения
  - директорию для моделей
  - путь к данным
  - адрес mlflow
-

Запуск обучения модели (train):
```bash
uv run main.py train
```
В результате обучения модели будут сохранены в формате `<model_name>_val_acc=<ACC>.ckpt`

Запуск тестирования модели:
```bash
uv run main.py test --checkpoint=breeds_model_val_acc=0.30.ckpt
```

Запуск классификации нового изображения:
```bash
uv run main.py infer --checkpoint=breeds_model_val_acc=0.30.ckpt --image-path=american_bulldog_120.jpg
```

Конвертация модели в onnx:
```bash
uv run main.py convert --checkpoint=breeds_model_val_acc=0.30.ckpt
# или
uv run main.py convert --checkpoint=breeds_model_val_acc=0.30.ckpt --savepath=triton/models/image_classifier/1/model.onnx
```

Запуск классификации нового изображения через triton:
```bash
uv run main.py infer-triton --image-path=american_bulldog_120.jpg
```

## Зависимости
Для управления зависимостями используется `uv`. Все версии зависимостей зафиксированы в pyproject.toml.

Для версионирования и хранения датасета и моделей применяется DVC (в целях учебного проекта я сделал локлаьное версионирование без s3)

---
## Модель
Модель разработана на фреймворке pytorch + pytorch-lightning. В качестве архитектуры с нуля выбрана сверточная нейронная сеть с 35 выходами (по количеству пород животных).
Инференс выполнен посредством конвертации модели в формат ONNX + размещение на triton inference server
